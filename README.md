# Jumpscare Quiz 👻

An interactive quiz that jumpscares you after every answer! Test your knowledge while experiencing spooky surprises.

## Features

🧠 **8 Trivia Questions**
- History, geography, science, and general knowledge
- Multiple choice answers
- Track your progress with a progress bar

😱 **Jumpscare Effect After Each Answer**
- Full-screen jumpscare with sound effect
- Random scary messages and animations
- Creepy flickering effects
- 2-second scare duration

📊 **Score Tracking**
- Real-time score calculation
- Final results with percentage
- Personalized feedback based on performance

🎨 **Spooky Design**
- Dark gradient background
- Red neon glowing effects
- Smooth animations and transitions
- Responsive design for all devices

## How to Play

1. Read the question carefully
2. Select your answer by clicking an option
3. Click "Next Question"
4. Experience the jumpscare! 👻
5. Answer all 8 questions to see your final score
6. Click "Take Quiz Again" to restart
